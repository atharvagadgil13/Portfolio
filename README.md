# Atharva Gadgil — The Data Playbook

A responsive, buildless portfolio with a sports-inspired forest green, cream, and orange visual direction.

## Preview

Run `python3 -m http.server 4173 --directory dist` from this directory, then open http://localhost:4173.

No package installation or build is needed. Serve the contents of `dist` with any static host.

## Features

- Filterable featured projects and accessible project-detail dialogs
- Experience, education, and skills based on the supplied resume
- Downloadable resume, email, LinkedIn, and GitHub links
- Responsive menu, keyboard focus styles, and reduced-motion support
- Original SVG court illustration and CSS project visuals

## Content sources

- Resume supplied locally and via Google Drive (matching content)
- https://github.com/atharvagadgil13
- Food_Inspection_ETL, customer-churn-xai, and 311_kc_service_requests README files
- Seattle pet license pipeline details from the resume, with the linked analysis repository

The Kansas City card's decorative bar chart is labeled as an illustration. Other displayed project metrics are sourced from the project READMEs. The project-detail dialog describes reported outcomes and tradeoffs.
